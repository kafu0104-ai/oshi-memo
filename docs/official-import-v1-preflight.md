## 既存の表示テスト3件の失敗原因

対象：`app/tests/entry-summary.test.cjs`。

このテストは物販の入場抽選・当落表示を期待していたが、共通のイベントデータに物販ジャンルが設定されていなかった。`app/src/components/event/GenreSummary.tsx` は、`mainGenreId === 'goods-sale'`、またはメインジャンル未設定かつ旧形式の物販タグがあるイベントに対して、この表示を行う。そのため3件とも空の表示となっていた。

今回、テストの共通データに `mainGenreId: 'goods-sale'` を追加。既存の3件の期待値は削除・緩和していない。加えて「旧形式の物販タグでも表示する」「物販以外には入場抽選を重複表示しない」の2件を追加した。5件とも成功。製品側の `GenreSummary.tsx` の表示条件は変更していない。
