# OshiMemo SVG Icon Set

OshiMemo用に作成した、全50種類のSVGアイコンです。

## 仕様
- 形式: SVG
- viewBox: 0 0 64 64
- 背景: 透過
- 主線色: #544C40
- アクセント: #E4C1B5
- ベース: #EAE6E1
- 線端: round
- 線結合: round

## 使い方
HTML:
```html
<img src="./01_shopping-memo.svg" alt="買い物メモ">
```

React:
```tsx
<img src="/icons/01_shopping-memo.svg" alt="買い物メモ" />
```

CSSでサイズを指定:
```css
.icon {
  width: 24px;
  height: 24px;
}
```

SVG内の色コードを置換するとテーマカラーを変更できます。
